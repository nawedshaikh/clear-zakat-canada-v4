# Clear Zakat Canada v4

React + Vite + TypeScript. No backend, database, account, or Python required.

## Run
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.

## Validate and deploy
- `npm test`
- `npm run build`
- `npm run preview`

Upload the generated `dist` folder to a static host, or connect the GitHub repository to Cloudflare Pages using build command `npm run build` and output directory `dist`.
